# Active

One-off projects that aren't a specific job: researching a new truck,
pricing out a new service, a flyer idea, testing a new tool.

- One folder per project: `active/<project-name>/`.
- If a project turns into a whole second business, the AI suggests giving it
  its own folder (with the `add-company` skill).
- Clear out finished projects during the weekly review. Nothing gets deleted
  without your OK.
