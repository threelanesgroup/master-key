# Jobs

One folder per job or customer: `jobs/<customer-name-or-address>/` (lowercase
with dashes, e.g. `jobs/smith-123-oak-st/`). Notes from the site visit,
photos, estimates, change orders, messages, and anything else about that job
live there.

Before working on a job, read everything in its folder. After the work, save
the result there with a dated, readable file name.

Your job software (Jobber, Housecall Pro, ServiceTitan) is still the source of
truth for schedules and invoices. These folders are for the notes and drafts
the AI works with.
