# Memory

Rules that hold for all of my work, whatever the job. Most of what I teach
you has a better home: see "Where it goes" in `AGENTS.md`. Keep this file
short.

## The bar

A line belongs here when it would change how you handle an estimate, a crew
text, and a review reply alike, and no context file, skill, or job folder
fits it better. It has to come from me, in one short sentence I've OK'd word
for word, with no passwords, account numbers, or private details. If it
overlaps a line that's already here, rework that line instead of adding one.

A line that clears the bar: "When a customer is upset, draft the reply, but
I call them first."
